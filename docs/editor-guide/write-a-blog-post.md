# Write a blog post

<!-- Video: add a link for "write-a-blog-post" under help.videos in site.profile.ts. -->

## Steps

1. From Start here, click **Write a blog post**.
2. Add a **Title**. Keep it under about **60 characters** so it fits in search results.
3. Check the **Slug**. This is the page address. Short and plain is best.
4. Write a **short summary** of one or two sentences. It appears on the blog list and in search results.
5. Add a **main image** and its alternative text. See "Replace a photo".
6. Write the article in the body. Use headings to break up long text and keep paragraphs short.
7. Choose a **category** and an **author**.
8. Click **Publish**.

## Good to know

- Set a **publish date** to keep the order of posts right.
- A post stays a draft until you publish, so you can come back to it later.
