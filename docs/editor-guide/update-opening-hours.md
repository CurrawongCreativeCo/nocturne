# Update opening hours

Your opening hours, phone number and address live in one place. Change them once and they update everywhere they appear, such as the footer.

<!-- Video: add a link for "update-opening-hours" under help.videos in site.profile.ts. -->

## Steps

1. From Start here, click **Business info and opening hours**.
2. Find **Opening hours**. Each row covers a set of days with the same hours, for example Monday to Friday.
3. Change the **Opens** and **Closes** times. Use 24-hour time, such as 08:00 or 17:30.
4. Tick **Closed on these days** for days you do not open. Days without a row show as closed.
5. Check the phone number and address while you are there.
6. Click **Publish**.

## Public holidays and special days

Use **Public holidays and special days** for one-off changes, such as Christmas Day. Days that have passed disappear from the site by themselves, so there is nothing to tidy up afterwards.

## Good to know

- Two rows for the same day make a split shift, such as a lunch break.
- The site and Google both read these hours, so keep them accurate.
